Mode

SHOW: a show file is running for real and the scheduler starts each show at its time. PROGRAMMING: a rehearsal is running; the scrubbing controls work and the scheduler starts nothing. NOT RUNNING: no show file is running; nothing reaches the rig until Run is pressed on the Schedule tab. To switch between Show and Programming: the Show and Programming switch on the Schedule tab's Show file card, then Run (Stop first if something is running).

Leaving this window

Closing this window is safe.
  • The show keeps running without it.
  • Minimize: Windows key + Down arrow.
  • Close: Alt+F4, or the button below.
More: this window is only a view; the engine runs on its own. The Minimize, Maximize and Close buttons are at its top right. Press Down arrow twice if it is maximized. A folder opened from this page comes to the front; if you do not see it, it is on the taskbar.
