LTC Player: quick card

The four big ones

ABORT
Emergency stop. Tap twice. Then Reset.
HOLD
Pauses the schedule. Resume carries on.
STOP SHOW
Ends everything. Rig goes dark. Run again.
RESET
Clears an Abort. Then arm again.

Five common fixes

Run is off
Press Run show. Shows then start on time.
Group says WAIT
Wait for it, then hold to arm.
Group says ARM AGAIN
Tap Disarm, then hold to arm.
An alert
Read it, fix it, tap Acknowledge.
No contact
Abort, Hold, Stop and Disarm still work.
