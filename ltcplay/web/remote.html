Show network, on this machine

Any device on that network can use this page. Never put remote access software, a tunnel or a port forward on this machine.

Show folder, on this machine

The show folder holds the show file (a .json), the renders it names and the show's music, as stems under the folder the show file names. There is no separate music folder.

Schedule: the show times

The scheduler starts a show at each time below (once Run has been pressed and the Fire & Ice settings say it performs). Edits here are written to the schedule file and loaded at once.

Mode

SHOW: a show file is running for real and the scheduler starts each show at its time. PROGRAMMING: a rehearsal is running; the scrubbing controls work and the scheduler starts nothing. NOT RUNNING: no show file is running; nothing reaches the rig until Run is pressed on the Programming screen.

Leaving this window

This window is only a view. Closing it never stops a show: the engine runs on its own. It is an ordinary window: the Minimize, Maximize and Close buttons are at its top right. To minimize without them, press the Windows key + Down arrow (twice if it is maximized); Alt+F4 closes it, or use the button below. A folder opened from this page comes to the front; if you do not see it, it is on the taskbar.
