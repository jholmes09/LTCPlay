Stream Deck operator, on this machine

Unlocks the deck's Arm, Start, Hold and Resume keys. This page needs no name.

Show network, on this machine

Any device on that network can use this page. Never put remote access software, a tunnel or a port forward on this machine.

Arming from a screen, on this machine

The Stream Deck has to be running for a hold to arm. Off: arm flames from the Stream Deck only; this rack screen can still purge, unlock and test lasers.

Announcement output, on this machine

While the show audio is running, announcements play through it, on the front left and right (Main L/R). The output picked here is used only when the show audio is not running. The system default is never used.

Live flame programming

Turned on here on the show machine only (Settings permission). Anyone can turn it off, from any screen, signed in or not. The steps for xLights are in LIVE_FLAME_PROGRAMMING.md.

Rig check (pre-roll)

Before every show the engine checks the rig by itself: audio, announcements, timecode, video, the flame link, the lasers and the network. Check the rig runs the same checks now, between shows: nothing is started, armed or played, and the screens go black until the next show.

Show folder, on this machine

The show folder holds the show file (a .json), the renders it names and the show's music, as stems under the folder the show file names. There is no separate music folder.
The show file is the playlist: which render (.fseq) plays at which timecode. The renders stay exactly as xLights made them.

Schedule: the show times

The scheduler starts a show at each time below (once Run has been pressed and the Fire & Ice settings say it performs). Edits here are written to the schedule file and loaded at once.

Hazers: show levels

Each armed hazer runs at these levels while a show plays. They take effect at once.

Screen: . Settings and logs:

Mode

SHOW: a show file is running for real and the scheduler starts each show at its time. PROGRAMMING: a rehearsal is running; the scrubbing controls work and the scheduler starts nothing. NOT RUNNING: no show file is running; nothing reaches the rig until Run is pressed on the Programming screen. To switch between Show and Programming: the Show and Programming switch on the Programming screen's Show file card, then Run (Stop first if something is running).

Leaving this window

This window is only a view. Closing it never stops a show: the engine runs on its own. It is an ordinary window: the Minimize, Maximize and Close buttons are at its top right. To minimize without them, press the Windows key + Down arrow (twice if it is maximized); Alt+F4 closes it, or use the button below. A folder opened from this page comes to the front; if you do not see it, it is on the taskbar.
